# p20 — Saju (사주 명리학) 미니앱

미니앱 우선 (TG / Toss / webview) + 다른 스토어 배포용. 사주팔자 차트 + 운세 분석. 엔터테인먼트 목적.

**p21 연동**: p20+p21이 리딩 기록을 공유합니다(Codex). 사주 해석이 타로 쪽 결과에도 참고되고, 반대도 마찬가지입니다.

**Core Features (MVP)**
- 생년월일시 + 성별 입력 → 천간지지 + 오행 + 대운/세운 간단 분석.
- 일일 무료 리딩 1회.
- 프리미엄 상세 해석(크레딧 언락).
- 음성 낭독(`voiceReading()`) + 결과 화면 시각효과(`p6LungSurpriseEye`, 고득점 결과에서 표시).
- 모든 리딩 기록 저장 + p21과 공유.

**결제**
- 무료 크레딧: 공용 레일(`p10-rail.js`, p21/p22와 잔액 공유) — 2026-08-20 배선 완료, 정상 작동. 단 이 크레딧을 소모하는 UI 버튼은 아직 없음(연결 준비만 된 상태).
- 유료 정식 리딩: 별도 결제 워커(`saju-pay.js`) 연동, 실제 가동 중이며 정상 응답.

**Monetization**
- 무료 1회/일 + 제한된 추가.
- 크레딧: 상세 리포트, 음성, 운세 아카이브 export.
- 월 구독 옵션 검토.

**Prototype**: PWA. Installable. Mini-app webview ready.

**Compliance Note**: 순수 엔터테인먼트. 확률/운세는 실제 예측이 아님을 화면에 명시. 의료·투자 조언 아님.
